# 时页 1.7.6

版本：`1.7.6+32`  
包名：`com.myhours.app`

## 变更

### 主题与外观

- 主题页新增 FlClash 式三模式取色器：网格（12×10 栅格）、光谱（2D 连续
  HSL）、滑块（HSV 三轨渐变），并提供 `#RRGGBB` 输入与亮/暗双小屏实时预览。
- 自定义主题色支持新增、编辑、删除与一键「恢复默认」，色板写入本机设置
  （不进 v4 备份契约）。
- 主题页顶部预览卡可点击底部图标，直接体验「滑动 / 淡入」两种切页动画。
- 主题切换改为单帧切完 + 旧帧 GPU 快照交叉淡出，不再逐帧补间 `ThemeData`。
- 修复高亮蓝（`#007AFF`）底色上文字发黑的问题：主色文字在满足 ≥4.0
  对比度时一律使用纯白。

### 计量单位

- 首页左上角标题跟随计量单位实时变化（工时 / 学时 / 次数 / 章数 / 页数 /
  里程），长按标题可直接弹出液态水滴菜单切换单位。
- 底部导航首项与桌面侧栏标签同步当前单位。
- 日历格子单位后缀改为跟随单位短写（原写死 `h`），角标、空态提示与
  「未来日期暂不可录入…」文案同步单位。

### 动效（对齐 FlClash v0.9.4 实测参数）

- 新增 `SpringCurve` 弹簧曲线原语与路由推入、确认弹窗、搜索变形三组弹簧。
- 二级页改为临界阻尼 300ms 弹簧推入，被覆盖页 `-30%` 视差位移 + `10%`
  压暗 + 运动中快照冻结，前缘附 6 段柔和投影条。
- 标签页切换改为 `PageView` 双模式：滑动模式跨页临时换槽、不构建中间页，
  淡入模式原地交叉淡入，两者都对运动中的页做快照冻结。
- 确认弹窗改为 `1.2 → 1.0` 弹簧入场；顶栏搜索展开/收起使用双弹簧。
- 首页指标卡新增原位编辑态：`±0.7°` / `1.25dp` 轻摆、拖动 `1.03×` 抬升。
- 按压反馈遵循「缩放与墨水互斥」，滚动容器内 140ms 后才显示按压。

### 性能

- 基础 Provider 全部改为 `.select` 细粒度订阅，并新增月度派生视图缓存，
  点选日历不再全量扫描记录。
- 账目列表改为 `CustomScrollView` + `SliverList.builder` 按需懒加载。
- 图表复用循环内 `Paint`；`sigma <= 0.1` 时跳过 `BackdropFilter` 离屏层；
  首页主卡、日历、账本汇总与摇摆卡片补齐 `RepaintBoundary` 隔离。

### 其他

- 区分未来月份与历史月份的提示文案，未来空白格子的日期垂直居中。
- 抬高移动端底部安全留白，避免末行被悬浮底栏裁切。
