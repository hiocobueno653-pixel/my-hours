# Agent 重构方案可行性审查（1.7.2）

对照 `My Hours Agent Refactoring Plan.md`，本轮按风险分级执行。

## 已实施

- M1 数据精度：Flutter/React 核心金额计算改为百分位定点，覆盖单日工资、月汇总、结算汇总与年度统计。
- M2 局部修复：每日快照优先原子 `rename`，保留 Windows 回退。
- M4 局部修复：弹窗起点改为一次性消费；透明度遮罩继续使用无过冲曲线。
- 日历拖动已移入独立组件，拖动时不再触发整页重建。

## 暂缓

- 持久化全面异步化与防抖写队列：会改变启动、退出和异常恢复时序，需要独立故障注入测试。
- 坏行容错导入：会改变“任一行损坏即整库回退”的既有安全语义，需先设计用户可见的丢弃报告。
- Riverpod 月度派生 Provider 与 `month_view.dart` 大拆分：当前日历拖动热点已隔离，继续拆分收益低于回归风险。
- Bento 头图、日历三层视觉编码与完整 odometer：属于视觉改版，不宜与本次稳定性修复一起落地。
- React 组件层全面替换舍入：数据层已对齐并通过测试，组件层保留冻结基线以减少双端漂移。
