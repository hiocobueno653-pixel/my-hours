# 时页 1.7.0

本版从参考视频中提取了两套交互语言：

- 弹窗：大圆角、半透明白色玻璃、背景高斯模糊、白色高光边、蓝色/红色胶囊按钮。
- 菜单：按钮液化膨胀成玻璃面板，面板带模糊、边缘高光与弹性回位。

同时实现了参考视频最后的「主题」页面。

## 新增

- 主题页：顶部实时预览、主题模式、纯黑模式、主题色、配色风格、底栏模式、选项卡动画、液态玻璃档位、系统字体说明、文本缩放。
- 主题色支持蓝、紫、粉、红、橙、黄、绿、灰及自定义色；切换后全局主色、月份胶囊、按钮、图表与 Dock 同步更新。
- 底栏支持「悬浮 / 固定」；选项卡支持「滑动 / 淡入」。
- 液态玻璃支持「无 / 标准 / 极致」；减动效时自动降级为 plain。
- 账本顶栏新增 fluid_glass 玻璃菜单：分类管理、回到本月、清除筛选。

## 重做

- 确认弹窗改为玻璃面板和 52dp 胶囊按钮，入场为淡入 + 缩放 + 轻微上移；点击空白一次关闭。
- 弹窗不再依赖 Material `Dialog` 的固定内边距，窄屏 320dp 不会横向溢出。
- 全局玻璃容器提高亮度，菜单面板保持白色玻璃可读性。
