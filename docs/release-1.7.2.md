# 时页 1.7.2

## 本轮修复

- 弹窗右上角的矩形截断亮边改为按超椭圆形状裁切，四角连续。
- 底部弹层的遮罩不再跟随 sheet 一起上滑，只在全屏原地渐暗。
- 确认弹窗按钮与主按钮统一为液体玻璃材质；弹层关闭按钮改为高亮玻璃。
- “液态玻璃”设置重新拆分作用范围：
  - 无：全界面普通磨砂；
  - 标准：仅底栏镜片折射，更省电；
  - 极致：全界面折射，设备不支持时自动降级。
- 首页日历支持跟手左右滑动，松手后旧月份与新月份交叉滑入/滑出。
- 主题页“配色风格”改为液体玻璃单选项菜单，从锚点液滴式展开。
- Flutter 与 React 数据层统一百分位定点金额舍入，修正 `1.005`、负数半值等边界。
- 每日快照优先使用同文件系统原子替换，Windows 测试环境保留安全回退。
- 弹窗起点改为一次性消费，连续弹窗不再复用旧按压坐标。

## 安装包

- `时页-1.7.2-release.apk`（通用 ABI）
- `时页-1.7.2-arm64-v8a-release.apk`（ARM64 手机）
