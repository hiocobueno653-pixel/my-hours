# 时页 1.7.5

版本：`1.7.5+31`  
包名：`com.myhours.app`

## 变更

- 参考重新克隆的 FlClash `9f2759e` 重构首页：移动端采用单列
  全宽今日卡、双月汇总卡和全宽日历，平板保留更紧凑排列。
- 今日卡计时区改为“状态在左、56dp 大按钮在右”：主按钮开始/暂停/继续，
  结束与放弃作为次级操作。
- Android 前台服务每秒刷新通知短文本，Chronometer、流体云和焦点通知
  读取的时间保持同步。
- 首页支持自定义卡片：本月数量、月工资、本月结余、今日账目均可添加、
  移除和长按手柄排序；今日概览与日历固定。
- 首页编辑态和设置页共享同一份卡片顺序，可立即恢复默认。
- 设置页合并主题、单位、首页卡片和实况通知为同一分组，减少卡片堆叠；
  通知行可直接打开系统通知设置；浅色模式下纯黑开关会禁用并说明原因。
- 清空全部数据会先结束计时、停止通知、清空文件和快照，并回到当前月。
- 页面标题、卡片内距、卡片间距和页面底部留白进一步收紧。
