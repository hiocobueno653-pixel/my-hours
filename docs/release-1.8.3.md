# 时页 1.8.3

日期：2026-11-28

版本：`1.8.3+39`

包名：`com.myhours.app`

## 变更

### 首页计时交互与水滴变形动效

- 今日工作台主计时操作升级为液态变形按钮：空闲与暂停态保持饱满圆钮与圆角播放三角，开始计时后按弹簧物理平滑旋展为 9 瓣圆润花形，图标矢量同步变形为双胶囊暂停键，按下回弹保留屏幕上方光源棱边与主题色漫射投影。
- 今日工作台右侧新增同心 12 瓣柔波背景，随「待记录 / 计时中 / 已暂停」在轻灰、透亮主题蓝与柔和琥珀间平滑旋展过渡，并同步优化右上时薪胶囊与右下编辑按钮在浅深双色模式下的边缘对比。
- 计时开始后，「完成 / 放弃」次操作胶囊从主按钮左侧平滑滑出，主按钮始终固定在原触控锚点不跳动，并满足 44dp 最小命中高度。

### 弹层与顶栏精修

- `SheetScaffold` 升级为「固定头部 + 可滚动正文 + 固定底栏」三段式布局，记工与记账长表单保存按钮常驻键盘上方且移除重复保存动作，正文拖动自动收起键盘。
- 日期导航收拢为 46dp 居中胶囊，弹层关闭键、日期步进键与文字操作按钮统一保留至少 44dp 触控盒。
- 顶栏玻璃控制组统一 44dp 高度，当前年份的月份胶囊省略年份前缀，跨年时自动保留完整年月；同步补充 `design.md` v6 设计规范。
