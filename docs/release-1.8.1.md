# 时页 1.8.1

日期：2026-11-28

版本：`1.8.1+37`

包名：`com.myhours.app`

## 变更

### 顶栏

- 工时与账本页把年月切换、搜索、更多操作收进同一枚液态玻璃控制组，减少独立白色胶囊造成的视觉割裂。
- 控制组保持每个动作独立可点击，同时统一到至少 44dp 的触控区；月份箭头由 26×32dp 扩大到 44×44dp。
- 顶栏按压反馈改为轻微缩放，避免小图标在按下时产生过强的弹跳感。
- 保留渐进模糊、镜面棱边、手指跟随高光和独立操作的无障碍语义。

### 验证与兼容

- 窄屏大字模式下顶栏不溢出；新增回归测试锁定月份箭头的 44dp 命中区和玻璃组合结构。
- Android 16 模拟器检查 320dp 与 411dp 宽度、浅色与深色模式；工时、统计、我的、账本顶栏均无溢出。
- 通用正式包覆盖安装到已有 1.8.0，冷启动无崩溃日志。
