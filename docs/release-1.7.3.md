# 时页 1.7.3

版本：`1.7.3+29`  
包名：`com.myhours.app`

## 变更

- 修复“我的”页 `OpenContainer` 入口的默认 elevation 黑边，统一无阴影、
  20px 起点圆角与 `fadeThrough` 转场。
- 减少动效开启时，设置页和“我的”页容器转场直接给终态。
- 计量单位覆盖 Bento 数量、日均和快捷档位；不同单位使用各自的快捷数值。
- 计时器支持跨日归属与「跨日」提示，结束写回开始日期；已结算日期禁止
  开始计时，避免改写结算记录。
- 开始计时后立即显示 `00:00` 与结束/暂停，不再短暂出现错误的双按钮状态。
- 计时 ticker 只在 Tab 可见且正在运行时刷新，离开 Tab 或暂停即停止。
- Android 通知改用单色计时图标；Android 13+ 首次计时请求通知权限；
  “实况通知”设置会显示权限是否授予。
- Android 前台服务在缺少计时快照时不再从 0 重新开始假计时。
