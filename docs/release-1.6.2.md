# 时页 1.6.2

## 数据安全

- 新增本机自动快照：每天首次打开或保存时自动留一份 v4 文档，保留最近 7 天。
- 「数据与备份」新增「本机自动快照」区，可查看快照时间、大小并手动恢复；恢复前会再次保留当前现场，并显示迁移对账结果。
- 空数据不生成自动快照；「清空全部数据」会同时删除每日快照和导入/恢复前的时间戳现场，避免清理后仍能从本机找回旧数据。

## 交互与无障碍

- 日编辑器日期两侧箭头可切前一天/后一天，跨月同步；今天之后禁用后一天。
- 键盘弹出时弹层保留状态栏安全区，标题、保存与关闭键不会被状态栏遮挡。
- 年度统计柱状图支持点选月份，选中槽位高亮，分类占比卡片同步更新。
- 今日卡片统一琥珀色「已结算」，并给无记录日期增加「待记录」；弱化文字对比度提升。

## 验证

- Flutter 全量测试 139 项通过。
- `flutter analyze` 无问题。
- 通用包与 arm64 包使用同一 release 签名，versionCode 递增。
