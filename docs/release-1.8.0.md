# 时页 1.8.0

日期：2026-11-28

版本：`1.8.0+36`

包名：`com.myhours.app`

## 变更

### 视觉与交互

- 按 Apple 最新材料指南整理界面层级：Liquid Glass 用于悬浮导航、顶栏和交互控件；内容卡使用稳定语义表面，在保持折射质感的同时优先保证文字清晰。
- 首页重做为更接近 iOS 的 Bento 结构：计时主卡、月指标、今日账目和月历形成明确层级；快捷增时改为单一分段胶囊，主按钮降低光晕与按压缩放，减少控件噪声。
- 统一连续超椭圆圆角、镜面棱边、半透玻璃、悬浮底栏和底部渐隐；修正底栏下方内容透出、账本空态重复主操作和统计空数据幻影高亮。
- 补齐统计与账本空态：没有工时或收支数据时显示紧凑引导，而不是大面积空白图表。
- 保留可中断的弹簧反馈、滑动动量、边缘橡皮筋和按压形变；系统减少动效与高对比设置会切换到清晰的静态表面。
- 统一大数字字距，改善窄屏、深色模式及系统大字下的阅读。

### 页面与功能

- 更新工时首页、月历、账本、统计、个人中心、主题、设置、备份和欢迎页的组件与布局。
- 优化账目筛选、月份切换、年度汇总、主题色预览及计时控件的反馈与状态展示。
- 趋势图和收支柱状图支持在图内横向拖动选月；滚轮日期与月份选择器补上选择触感和“回到今天 / 本月”快捷操作。
- 账本新增历史月份回本月提示、筛选小计、删除撤销和更清晰的分组账目列表。
- 保持本地备份、数据恢复、CSV 导出、已结算记录和纯工时版本流程。
