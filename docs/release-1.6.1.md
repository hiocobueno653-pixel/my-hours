# 时页 1.6.1

## 体验

- 日编辑器标题行新增前一天/后一天箭头；跨月会同步月份上下文，今天之后禁用
  后一天，离开未保存输入前先确认。键盘弹出时弹层保留状态栏安全区。
- 年度统计的每月收支柱状图支持点选月份，选中的槽位有浅色底带、加粗月份
  标签和 `selectionClick` 触觉，同时切换下方分类占比卡片。
- 今日卡片统一结算状态为琥珀色，并给无记录日期增加「待记录」状态；月明细
  的结算图标同步为琥珀色。
- 提高弱化文字 `text3` 对比度，未来日期保留更清晰的禁用提示。
- 导出文件名统一使用「时页」前缀；移除未使用的 Outfit 字体资源。

## 验证

- `flutter analyze` 无问题。
- Flutter 全量测试 137 项通过。
- 通用 APK 与 arm64 APK 使用同一 release 签名，versionCode 递增。
