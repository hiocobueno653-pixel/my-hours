# 时页 1.7.4

版本：`1.7.4+30`  
包名：`com.myhours.app`

## 变更

- 计量单位继续覆盖日编辑器快捷档位、年度统计、工资/单位价命名、
  月明细、CSV 导出与备份页。
- 小时仍显示“时薪 / 元/时”；学时、次数、章、页、公里显示“单价”和对应
  单位后缀。
- CSV 表头和文件名跟随当前单位，底层 v4 数据与金额口径不变。
- 实况通知设置项可直接打开本应用的系统通知设置；从系统设置返回时自动
  刷新权限状态。
- 计时结束会立即落盘，再清除计时快照，降低进程在合并写盘窗口被杀时
  丢失计时的风险。
- 计时写入遵守每日记录上限；只读或已结算状态下可确认放弃计时，避免
  通知和计时状态永久悬挂。
- 日历、月明细与设置页的剩余“记工 / h”文案改为单位无关表述。
