# 时页 1.6.3

本版按 2026-11-15 代码审计方案，优先修复“存不住”和“输入后无法保存”，
并收紧顶栏、图表与启动页的绘制成本。

## 修复

- 隔离态不再允许普通写操作推进内存状态；全局常驻保存失败提示，磁盘错误可重试。
- 清空数据会同时复位存储隔离态，之后可以重新建立存档。
- 金额、日薪、预算编辑框不再预填千分位；粘贴 `1,234.56` 会清洗后保存。
- 账目支持跨月保存后自动切换月份；账目日期不能超过今天。
- 分类环图拆分收入/支出，筛选 key 不再与分类名冲突。
- ID 改为带进程内序号的单调生成，避免同一微秒碰撞。
- 每日快照先检查当天文件；保存指纹缓存，避免每次重复读取主文档。
- 图表使用 `listEquals` 和 `RepaintBoundary`；顶栏渐进模糊从 7 带降为 2–4 带。
- 三个 Tab 首次访问才构建；减少首屏与无关页面重算。
- 修正深色主按钮、告警条和危险确认按钮的对比度。
- 欢迎页 CTA 对比度、动画对象生命周期和撤销/关闭触控热区修正。
- 统一支持年份为 2000–2100，导入不再接受界面无法到达的日期。
