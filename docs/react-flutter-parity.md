# React 1.2.0 ↔ Flutter 1.6.2 功能对照

本轮以仓库里的 React 版（`src/`，冻结在 `react-1.2.0-baseline`）为功能基准，
把用户可见的布局与交互补进 Flutter 版，同时保留 FlClash 蒸馏后的视觉语言。

## 已对齐

| 区域 | React 版 | Flutter 版 |
| --- | --- | --- |
| 月份切换 | 左右箭头 + 月份弹层 + 年份快捷切换 | 同左（`lib/ui/month_picker.dart`） |
| 月环比 | 「比上月 +x 小时（+y%）」 | 记工页工时卡、我的页数据带 |
| 回到本月 | 非当前月显示 | 记工页显示 |
| 今天工作区 | 今天工时、收入、账目数、账目列表、记一笔/记工时 | 同左（今天卡 + 今日账目卡；记一笔带当天日期） |
| 月历 | 周一起始、每日工时、收入/支出/结算圆点、未来日期禁用、图例、明细入口 | 同左 |
| 月历手势 | 左右滑动切月 | 同左 |
| 记工导出 | 工时 CSV / Excel | 工时、账本、月中概览 CSV（`lib/ui/export_sheet.dart`） |
| 记账汇总 | 结余 + 收入/支出 + 今天账目行 | 同左 |
| 记账筛选 | 全部/收入/支出/分类 chips | 同左 |
| 超预算 | 超预算提示条 | 同左（记工/记账页与我的页预算卡） |
| 账目行 | 分类、备注、关联工时、金额 | 同左（补了关联工时） |
| 记账头部 | 新增、分类管理、导出 | 同左 |
| 我的页 | 月数据带、工资面板、预算面板、月环比、仅本机标记 | 同左（工资/预算为可点开的摘要卡） |
| 日编辑 | 未来日期拒绝、快捷工时含「休息」、前后切日 | 同左（日期两侧箭头切前一天/后一天，跨月同步） |
| 图表交互 | 月度收支柱状图可点选月份 | 同左（点击柱形切换分类占比月份，带选中底色与触觉） |
| 自动备份 | 自动快照与状态 | 每日本机快照（保留 7 天）+ 备份页手动恢复与对账 |

## 仍保留的差异

| 项 | 说明 |
| --- | --- |
| Excel 导出 | Flutter 目前只出 CSV；`backup.dart` 已有 xlsx 行数据构建器，接入表格库即可补齐。 |
| 二级页右滑返回 | React 的「我的」子页跟手右滑；Flutter 用系统返回键与路由转场。 |
| 设置位置 | React 把大字/主题放在「数据与设置」；Flutter 收在「使用设置」独立页。 |
| 工作管理入口 | React 在工资面板头部；Flutter 在工资面板底部按钮。两者都支持新增/改名/改时薪/删除（默认工作不可删除）。 |

## 不变量

两版共享同一套数据契约与金额口径：

- 备份 JSON v4 字段不变；
- `fixedPay > 时薪快照 > 工作当前时薪`；
- 逐条舍入后累加；
- 已结算且工资 > 0 才生成 `wage-<date>` 收入账目；
- Flutter 全量数据/迁移/UI 用例全部通过。
