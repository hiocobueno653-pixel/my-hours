# 时页 1.7.1

本版按参考弹窗修正遮罩表现：

- 确认弹窗与底部弹层不再对整屏背景做高斯模糊。
- 背景改为纯压暗遮罩：浅色约 24%，深色约 46%。
- 玻璃弹窗面板、按钮材质、缩放淡入动效保持不变。
- 弹层可读性不依赖背景模糊，长时间打开时少一层全屏 GPU 采样。
- 移除自定义 TIMEPAGE 开屏加载动画和强制 2 秒等待；本地数据准备期间保留原生启动页，准备完成后直接进入欢迎页或主页。
- 弹窗从最近一次按压的位置附近生长，关闭时沿同一路径收回；打开和退出共用同一条缓动。
