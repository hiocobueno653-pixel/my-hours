# ADR-0003：用 Flutter 重做客户端

- 状态：已采纳
- 日期：2026-11-08
- 取代：`src/`（React + Capacitor）作为主客户端，React 版冻结在 `react-1.2.0-baseline`

## 背景

React + Capacitor 版在 1.2.0 达到功能完整，但三个问题反复出现：

1. 144 KB 的 `index.css` 与 18 个组件各自维护动画，同一个「按压反馈」有四种实现；
2. WebView 里的滚动/手势/键盘行为在低端安卓机上不稳定，无法通过 CSS 修复；
3. 三个页面各自持有月份状态，切 tab 后月份不同步——这是状态设计问题，不是样式问题。

## 决策

用 Flutter 3.47 重做客户端，**Android 优先，v1 不发布 Flutter Web**。

保留的东西（不重写）：

- **数据契约**：备份 JSON v4 作为唯一存储格式与迁移通道，字段名与语义不变；
- **金额口径**：`fixedPay > 快照时薪 > 工作当前时薪`，逐条舍入后累加；
- **结算对账**：`settled && pay > 0` 生成 `wage-<date>` 收入账目，否则删除；
- **纯函数**：`src/data/*.ts` 逐文件移植到 `lib/data/*.dart`，用例一并移植。

丢掉的东西（有意为之）：

- localStorage + 三份备份字符串 → 单 JSON 文档 + 原子写 + `.bak`/`.bak.1`；
- Zustand → Riverpod 3 `Notifier`；
- 第三方图表 → 4 个 `CustomPainter`（柱/环/进度/趋势）；
- prism_ui 依赖 → 只 vendor 允许的子集（见 ADR-0002）。

## 后果

### 好的

- 60 fps 的手势与转场不再依赖浏览器；Dock 指示器、弹层、返回栈都是原生实现。
- 数据层成为纯 Dart，87 个用例可在 CI 里秒级跑完（无需浏览器）。
- 金额口径有 golden case 表锁死，重构不会静默改变一分钱。

### 代价（必须记录，不要假装没有）

| 项 | 旧版 | 新版 | 说明 |
| --- | --- | --- | --- |
| APK 体积 | 4.4 MB | 56 MB（全 ABI）/ ~20 MB（单 ABI） | Flutter 引擎固有开销，无法回到 WebView 量级 |
| 冷启动 | ~1.2 s | 模拟器 15–25 s，真机未测 | x86_64 模拟器无 GPU 加速，数字不代表真机 |
| Web 版 | 有 PWA | 无 | React PWA 冻结维护，不再加功能 |
| 热更新 | 支持（Web） | 不支持 | 走应用商店/侧载更新 |

体积与首帧是这次重做**真实付出的代价**，不是可以糊过去的细节。

## 未完成（v1 范围外）

- iOS 构建（代码无平台特定依赖，但未验证）；
- 自动备份定时器（旧版 `autoBackup.ts` 的每日导出）——当前只有手动导出；
- 图表交互（点击柱子看当天明细）；
- API 24–26 真机验证（`BackdropFilter` 玻璃在低端机可能掉帧）。
