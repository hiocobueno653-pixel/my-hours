# ADR 0010：FlClash 式仪表盘与首页卡片自定义

## 状态

已采纳（1.7.5）。

## 参考

- 重新克隆 `https://github.com/chen08209/FlClash`，参考提交 `9f2759e`。
- 只参考页面层级、移动端卡片顺序、桌面/移动断点、编辑器和行高规律；
  没有复制 prism_ui、FlClash 源码、图标或资源，项目仍使用自己的 Material
  组件与时页令牌。

## 决策

- 首页从“今日窄卡 + 两张月卡并排”的 1+2 布局改为移动端单列：
  全宽今日主卡 → 两张等宽月汇总卡 → 全宽日历。
- 今日主卡使用 FlClash 仪表盘的大主操作结构：状态和读数在左，56dp
  蓝色主按钮在右，承担开始、暂停、继续；结束和放弃保持次级胶囊。
- 首页可选卡由 `DashboardCardIds` 管理，默认“本月数量 + 本月工资 +
  今日账目”，还可添加“本月结余”，可通过长按拖拽手柄排序。
- 今日概览与本月日历固定；编辑器用紧凑 62dp 行表达卡片，避免把整张
  日历拖进拖动浮层。
- 首页卡片顺序存入 SharedPreferences，不进 v4 备份契约。
- 设置页提供当前卡片数量与“恢复默认”；清空全部数据会先结束计时、
  停掉通知并回到当前月。
- 设置页改为分组列表：主题、单位、首页卡片、实况通知同组；
  阅读/动效开关和危险操作独立成组，减少多卡堆叠的空白。
- 页面间距以 8dp 为主；月卡、今日卡和日历之间不再使用 12dp 大段留白。
- 页标题统一 24dp；窄屏或大字号时月份标签缩短为“11月”，给三个顶栏
  操作留出稳定空间。

## 后果

- 手机首屏的信息层级更接近 FlClash：一个主状态、两张小指标、一个主内容区。
- 用户可自行添加/移除/排序月汇总卡，固定卡不会被误删。
- 老版本没有卡片顺序设置时使用默认“月数量 + 月工资 + 今日账目”；
  不存在数据迁移。
